JAWABAN BAGIAN I — ANALISIS KODE & DEBUGGING

1. Kutip dan Operator
Kode:
$harga = 500; $jml = 4;
echo 'Total: $harga' . ' | ' . ($harga * $jml);

Output:
Total: $harga | 2000

Alasan:
Teks yang menggunakan kutip tunggal tidak mengembangkan/interpolasi variabel. Karena itu, $harga dicetak sebagai teks biasa. Perhitungan $harga * $jml menghasilkan 500 * 4 = 2000.

2. Perbedaan == dan ===
Kode:
$kode = "01";
if ($kode === 1) echo 'A';
elseif ($kode == 1) echo 'B';
else echo 'C';

Huruf yang tercetak: B

Alasan:
Operator === membandingkan nilai sekaligus tipe data. String "01" bertipe string, sedangkan 1 bertipe integer, sehingga kondisi pertama false. Operator == melakukan perbandingan longgar dengan konversi tipe, sehingga kondisi kedua bernilai true dan mencetak B.

3. Scope Variabel
Error:
Undefined variable $diskon.

Alasan:
Variabel $diskon dibuat di luar fungsi. Variabel lokal di dalam fungsi tidak otomatis dapat mengakses variabel global.

Perbaikan yang disarankan:
function hitung($h, $diskon) {
    return $h * (1 - $diskon);
}
$diskon = 0.10;
echo hitung(50000, $diskon);

Hasil perhitungan: 45000.

4. Array dan Key
Warning:
Undefined array key "member".

Alasan:
Array $trx hanya memiliki key 'pelanggan' dan 'total'. Key 'member' tidak tersedia.

Solusi menggunakan ??:
echo $trx['member'] ?? 'Bukan member';

Operator ?? memberikan nilai pengganti jika key tidak ada, sehingga warning dapat dihindari.

5. Keamanan XSS
Dampak:
Jika input pengguna berisi <script>alert('XSS')</script> dan langsung dicetak ke halaman, browser dapat menjalankan JavaScript tersebut. Ini merupakan risiko Cross-Site Scripting (XSS).

Fungsi pencegah:
htmlspecialchars($_POST['pelanggan'] ?? '', ENT_QUOTES, 'UTF-8');

Fungsi tersebut mengubah karakter khusus HTML menjadi entitas sehingga input ditampilkan sebagai teks, bukan dijalankan sebagai kode HTML/JavaScript.
